One-Click Publishing
Connect to GitHub so "Publish Changes" pushes everything live automatically. Set this up once — then it's one tap forever.
⚪ Not connected yet
How to set this up (one time, ~10 min)
  1. Create a free account at github.com if you don't have one.
  2. Create a new repository (click the + in the top right → New repository). Name it anything, set it to Public.
  3. Upload all your site files to it (drag and drop them onto the repo page).
  4. Go to netlify.com → Add new site → Import from Git → connect your GitHub repo. Netlify will now auto-deploy whenever the repo changes.
  5. Back on GitHub: click your profile photo → Settings → Developer Settings → Personal Access Tokens → Fine-grained tokens → Generate new token.
  6. Under "Repository access" choose your site repo. Under Permissions → Repository permissions → set Contents: Read and write. Generate the token and copy it.
  7. Paste the token below along with your GitHub username and repo name, then hit Save.
Fine-grained token with Contents: Read and write on your repo.

Quick Guide
How to use this admin panel.
  • Menu ItemsAdd, edit, or delete items. Use the exact filename for photos already in your website folder.
  • Sold OutHit "Sold Out" on any item — a red badge shows on the website. Hit "Available" to bring it back.
  • EventsUpdate where and when people can find the truck. Keep Facebook updated too.
  • PhotosUpload a new founder photo or add extra gallery images directly from your phone — no files to copy.
  • BackupDownload a backup before big changes. If your browser clears its data, restore from the backup file.
